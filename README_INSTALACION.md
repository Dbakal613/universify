# Universify V2

## Reemplazo recomendado

1. Detén el servidor con `Control + C`.
2. Haz una copia de seguridad de tu proyecto actual.
3. Copia estas carpetas al proyecto original:
   - `app`
   - `components`
   - `lib`
4. Reemplaza los archivos cuando Finder lo pregunte.
5. Ejecuta:
   ```bash
   npm run dev
   ```

## Rutas

- `/` — Qué estudiar hoy + asistencia
- `/trabajo-autonomo` — Repaso recomendado diario
- `/horario` — Horario semanal
- `/calendario` — Calendario mensual
- `/ramos` — Información, notas y asistencia

## Persistencia

Los datos se guardan en `localStorage` del navegador.
